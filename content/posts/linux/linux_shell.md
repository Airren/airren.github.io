变量

| cmd  | Description                                                  |
| ---- | ------------------------------------------------------------ |
| $@   | 所有参数(把所有参数视为一个整体)@跟*类似，但是可以当作[数组](https://so.csdn.net/so/search?q=数组&spm=1001.2101.3001.7020)用 |
| $*   | 所有参数（单个参数视为一个整体）                             |
| $#   | 所有参数的个数                                               |
| $?   | 上一个命令的执行结果，0 表示成功                             |
| $n   | 第n个参数                                                    |
| $0   | shell文件名                                                  |
| $$   | shell pid                                                    |
| $!   | shell 最后运行的后台process 的pid                            |
| $-   | 表示shell使用的当前选项，与set命令功能相同(**himBH**是默认值，你可以通过 set 命令来设置或者取消一个选项配置，set -x 这个可以打开 shell 的调试开关，调试 shell 脚本非常有用，这个时候再检查下 $- 变量的值**himxBH**，可以看到多了 x) |
| &    | 在脚本中定义一个方法想让它后台运行，调用该方法时 方法名+空格+&，执行某个命令让其后台执行并且不输出报错信息 >/dev/null 2&1 & |
